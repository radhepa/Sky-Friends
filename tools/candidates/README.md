# The candidates that weren't picked

Before the Cirri were chosen (2026-10-10), three sky peoples were designed side by side. These two lost:

- `cumulin.py`: the Cumulin, short round balloon-sailors who carry a living cloud (their billow) on their backs.
- `nimbari.py`: the Nimbari, serpent-tailed storm folk with copper armour and lightning in their fins.

They are kept for reference only: they are not part of the mod, and running them writes their model files into
`src/`, which the build would then ship. Delete those files again if you run them.
